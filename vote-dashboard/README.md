# 返场投票 · 票数监控台

王者荣耀周年庆「限定皮肤返场投票」的实时票数抓取与排名看板。
展示每款参选皮肤的**名次、票数、与上一名的差距**，并标出返场线。

```bash
cd 王者荣耀返场投票监控
python3 server.py
```

然后浏览器打开 <http://127.0.0.1:8787>

## 二、数据从哪来（重点）

投票是**游戏内活动**，官方没有提供免登录的公开票数网页。票数由腾讯的活动系统接口返回：

```
https://smoba.ams.game.qq.com/ams/ame/amesvr     （POST）
```

返回的 JSON 里，`modRet.sOutValue2` 是一串皮肤编号（`v_1|v_2|v_3|...`），
`modRet.sOutValue3` 是对应的票数（`123|456|789`），两者**按下标一一对应**。

**关键**：每一次活动的 `iActivityId`、`iFlowId`、`g_tk` 都不一样，所以不能写死。
程序已经把这三个参数做成了可在页面上填写的配置。

### 拿到当期参数的方法

1. 手机连电脑代理（Charles / Fiddler / HttpCanary 都行），或用电脑开一个模拟器登游戏。
2. 进入游戏内活动 **周年庆 → 返场投票 → 限定皮肤返场投票**，翻一下排行榜。
3. 在抓包记录里找到发往 `smoba.ams.game.qq.com/ams/ame/amesvr` 的请求，
   把 URL 和表单里的 `iActivityId`、`iFlowId`、`g_tk` 抄下来。
4. 回到看板的「数据源与导入」页，填进对应输入框，点**保存配置**，再点**立即抓取一次**。
   - 成功 → 排行榜立刻出数据，之后按设置的间隔自动轮询。
   - 失败 → 页面会把接口的**原始响应**打出来，照着排查（最常见的报错是「活动不存在」，说明活动号填错了或活动已结束）。

### 编号 → 英雄/皮肤 的映射

接口返回的是 `v_1` 这类编号。抓包时页面上会显示编号对应的皮肤，
按 `v_1 = 妲己|愿照·众生和` 的格式每行一条，填进「编号 → 英雄/皮肤 映射」里保存即可。
不填也能看，但列表里显示的会是编号本身。

### 抓不到怎么办：手动导入

「手动导入」是兜底通道，两种格式都认：

```
妲己 愿照·众生和 18910170
司空震 愿照·山河定 12701488
```

或者直接粘两行编号/票数串：

```
v_1|v_2|v_3
123456|78901|5000
```

导入一次 = 存一条快照，多导几次就能画出票数增长曲线。

## 五、已知限制

- 参数靠抓包取得，**没有抓包就拿不到实时数据**，此时只能用手动导入。活动结束后接口会失效，参数换到下一期也不能复用。
- 抓取的是公开的活动排行榜票数，**请自用、低频轮询**（默认 300 秒一次），不要用于商业用途或高频压对方接口。
- 轮询间隔最小 30 秒；间隔越短越可能被限流。
