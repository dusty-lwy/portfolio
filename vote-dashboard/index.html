为什么还没有数据

王者荣耀的返场投票是游戏内活动，官方没有公开的免登录票数网页。程序按 数据源配置.json 里的 iActivityId / iFlowId / g_tk 去活动接口抓取，这三个参数每期都变，需要抓包拿到后填进仓库里的配置文件（见仓库 README 的抓包教程）。

没有参数时的兜底办法：在本地跑 python fetcher.py --import "英雄 皮肤 票数" 导入一条快照，再把 data/ 目录提交上来，看板立即能显示。
